## Завдання 1 — мінімальне значення в BST (30 балів)

**Файл:** `task_1.py`.

Функція `find_min(root)` переходить через дочірній вузол `left`, доки не досягне крайнього лівого вузла. Саме він містить найменше значення у BST.

Для порожнього дерева повертає `None`.

**Складність:** `O(h)` часу та `O(1)` додаткової пам'яті, де `h` — висота дерева. Для збалансованого дерева `h = O(log n)`, для виродженого — `h = O(n)`.

Запуск:

```bash
python3 task_1.py
```

Результат:

```text
BST values: [10, 5, 15, 3, 7, 12, 18]
Minimum value: 3
```

## Завдання 2 — сума всіх значень BST (30 балів)

**Файл:** `task_2.py`.

Функція `sum_tree(root)` обходить усі вузли дерева у глибину (DFS) за допомогою стека та підсумовує їхні значення. Для порожнього дерева повертає `0`. Ітеративний обхід не залежить від обмеження глибини рекурсії Python.

**Складність:** `O(n)` часу та `O(h)` додаткової пам'яті, де `n` — кількість вузлів, `h` — висота дерева.

Запуск:

```bash
python3 task_2.py
```

Результат:

```text
BST values: [10, 5, 15, 3, 7, 12, 18]
Sum of all values: 70
```

## Завдання 3 — оптимальне об'єднання кабелів (40 балів)

**Файл:** `task_3.py`.

Алгоритм використовує **мінімальну купу (Min Heap)** з `heapq`. На кожному кроці він вилучає два найкоротші кабелі, з'єднує їх, додає довжину нового кабелю до загальних витрат і повертає новий кабель у купу. Така жадібна стратегія мінімізує суму всіх з'єднань (за принципом оптимального злиття, як у побудові дерева Гаффмана).

Функція `minimum_connection_cost(lengths)` повертає мінімальні загальні витрати, а `optimal_connection_plan(lengths)` — також порядок з'єднань. При нулі або одному кабелі результат `0`. Вхідні дані не змінюються. Приймаються невід'ємні цілі довжини; інші значення спричиняють `ValueError`.

**Складність:** `O(n log n)` часу та `O(n)` додаткової пам'яті: `heapify` має `O(n)`, а `n - 1` з'єднань виконують операції `heappop`/`heappush` в `O(log n)`.

Запуск:

```bash
python3 task_3.py
```

Результат для `[4, 3, 2, 6]`:

```text
Cable lengths: [4, 3, 2, 6]
Connect 2 + 3 = 5 (cost: 5)
Connect 4 + 5 = 9 (cost: 9)
Connect 6 + 9 = 15 (cost: 15)
Minimum total cost: 29
```

## Перевірка

Запуск усіх автоматизованих тестів із кореня репозиторію:

```bash
python3 -m unittest discover -s tests -v
```

Тести перевіряють мінімум і суму для звичайних, порожніх, вироджених дерев, дублікати, від'ємні значення, граничні випадки для кабелів, відсутність мутації вхідних даних та обробку помилок.

Для завдання 3 також використовується **повний перебір усіх можливих пар з'єднань** на багатьох невеликих наборах: він незалежно підтверджує оптимальність жадібного рішення.

## Висновки

1. У BST мінімум знаходиться рухом у крайню ліву гілку; повний обхід не потрібен.
2. Для обчислення суми потрібно відвідати кожен вузол рівно один раз.
3. Для мінімізації витрат на з'єднання кабелів потрібно щоразу об'єднувати два найкоротші кабелі; `heapq` ефективно підтримує мінімум.
4. Вибір структури даних суттєво впливає на складність: `O(h)` для мінімуму в BST, `O(n)` для суми, `O(n log n)` для оптимального злиття.
